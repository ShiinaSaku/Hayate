# @shiinasaku/hayate

Install the Hayate encrypted LAN file transfer CLI from npm.

```bash
npm install -g @shiinasaku/hayate
hayate --help
```

This package ships a platform-agnostic wrapper. The first time you run it, npm
installs the correct native binary for your OS and architecture as an optional
dependency.

Supported platforms: macOS (Intel/Apple Silicon), Linux (x64/ARM64), Windows
(x64/ARM64), and Android (Termux x64/ARM64).

For more details, visit <https://hayate.shiina.xyz>.

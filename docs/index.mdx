Hayate (疾風, "gale") moves files directly between devices on the same network. You run one command on each machine, and Hayate handles discovery, encryption, compression and verification.

```bash
hayate send ./photos.zip
```

```text
   ●  Pairing code
   forest-river-mango-silver-orbit

   Receiver runs:  hayate receive --code "forest-river-mango-silver-orbit"
```

## Why Hayate

- **No infrastructure.** There is no relay, rendezvous server or SSH daemon. Two devices on the same network are enough.
- **Authenticated by a phrase.** Hayate stretches a 5-word pairing phrase with memory-hard Argon2id and mixes it into the key exchange. Only a peer that knows the phrase can derive the session key.
- **Fast where it counts.** Hayate uses QUIC with 4 MiB frames and asynchronous read-ahead. Compression and encryption run on dedicated worker threads.
- **Resumable and verifiable.** Interrupted single-file transfers continue from the last frame boundary. The checksum covers the whole file, including the part received before the interruption.
- **Inspectable.** The local dashboard shows peers and history without sending anything off your machine.

## Features

| Area | What you get |
| --- | --- |
| Transport | QUIC on [compio](https://github.com/compio-rs/compio) (io_uring, IOCP or kqueue), 4 MiB frames, 8-deep read-ahead |
| Encryption | Ephemeral X25519, Argon2id phrase stretching, HKDF-SHA256, per-frame AES-256-GCM or ChaCha20-Poly1305 |
| Pairing | 5-word phrases, mDNS and UDP discovery, direct `ip:port`, optional `--passphrase` |
| Integrity | BLAKE3 (default) or SHA-256 over the plaintext, plus size and frame validation on receive |
| Resume | Single-file transfers continue from the last 4 MiB boundary |
| Compression | zstd level 1, skipped for compressed formats and turned off for incompressible data |
| Control | Bandwidth limits, named peers, an interactive receiver picker and overwrite policies |
| Dashboard | `hayate web`: drag-and-drop send, receive listener, live progress, history and token auth |
| Scripting | NDJSON events with `schema: hayate/1`, stable exit codes, `--quiet` and `--verbose` |
| Platforms | One static binary each for macOS, Linux and Windows. Android (Termux) builds from source. |

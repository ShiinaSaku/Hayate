# CLI Command Reference

The `hayate` binary provides a CLI interface for peer-to-peer transfers. This page lists all commands, subcommands, and flags available.

---

## `hayate receive`

Starts the local receiver node to listen for incoming file or directory transfers.

### Usage
```bash
hayate receive [OPTIONS]
```

### Options

| Flag | Description | Default |
| --- | --- | --- |
| `-b, --bind <IP>` | The local interface IP to bind the QUIC UDP socket to. | `0.0.0.0` (all interfaces) |
| `-p, --port <PORT>` | The UDP port to listen on. | `50001` |
| `-o, --output <DIR>` | The output directory where received files will be saved. | `.` (current directory) |
| `--auto-accept` | Accept all incoming transfers immediately without prompting the user. | `false` (interactive prompt) |
| `--code <PHRASE>` | Pairing code phrase to enable LAN broadcast discovery. | None (Direct Mode only) |
| `--no-tui` | Disable the progress bar and terminal user interface. | `false` |

### Examples

```bash
# Listen on port 50002 and save downloads to ~/Downloads
hayate receive --port 50002 --output ~/Downloads

# Wait in pairing mode with auto-acceptance
hayate receive --code "cherry-blossom-spring" --auto-accept
```

## `hayate send`

Transmits a file or directory to a remote receiver node.

### Usage
```bash
hayate send [OPTIONS] <PATH> [TARGET]
```

### Arguments

- `<PATH>`: Path to the local file or folder to send.
- `[TARGET]`: The destination address in the format `IP:PORT` (e.g. `192.168.1.100:50001`). Required in Direct Mode; omitted in Pairing Mode.

### Options

| Flag | Description | Default |
| --- | --- | --- |
| `--peer <ADDR>` | The receiver's address. Equivalent to specifying the `TARGET` positional argument. | None |
| `--code <PHRASE>` | Pairing code phrase to discover the receiver across the LAN. | None (generates one if no target specified) |
| `-z, --compress` | Enables compression using Zstd level 1 on raw payload blocks. | `true` |
| `--hash <ALGO>` | Integrity algorithm for payload verification: `blake3`, `rapidhash`, or `sha256`. | `blake3` |
| `--no-tui` | Disable progress bar updates. | `false` |

### Examples

```bash
# Send a directory directly to a specific IP address
hayate send ./target-folder 192.168.1.50:50001

# Send a file in pairing mode with custom hash algorithm
hayate send archive.zip --code "forest-river-mountain" --hash rapidhash
```

## `hayate discover`

Scans the local subnet for active Hayate receivers.

### Usage
```bash
hayate discover [OPTIONS]
```

### Options

| Flag | Description | Default |
| --- | --- | --- |
| `-t, --timeout <SECS>` | Scan timeout in seconds. | `3` |
| `--cidr <RANGE>` | Custom subnet range to scan (e.g., `192.168.1.0/24`). | Auto-derived from active interfaces |

### Examples

```bash
# Scan default network interface
hayate discover

# Scan a specific network subnet range
hayate discover --cidr 10.0.0.0/24 --timeout 5
```

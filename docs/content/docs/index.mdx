# Hayate Documentation

Hayate is an encrypted, compressed, blazing-fast LAN file transfer tool. It sends files and directories directly across your local network using QUIC transport, X25519 key agreement, and hardware-accelerated AEAD encryption.

## What makes Hayate different?

<Callout type="info" title="Privacy by design">
  Hayate never touches the cloud. Files travel directly between two devices on the same network. Pairing uses a four-word code phrase, and every transfer gets its own ephemeral encryption key.
</Callout>

| Feature | Hayate | Cloud drives | USB sneakernet |
| ------- | ------ | ------------ | -------------- |
| Speed | Wire-speed QUIC | Internet upload capped | Walk to the other machine |
| Privacy | End-to-end encrypted | Server-side encrypted | Physical loss risk |
| Setup | One command | Account + app + sync | Cable + port availability |
| Cross-platform | macOS, Linux, Windows, Android | Native clients only | USB-C / USB-A mismatch |

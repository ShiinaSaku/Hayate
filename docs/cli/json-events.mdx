---
title: "JSON events"
description: "The NDJSON events hayate prints with --format json: event names, fields and the hayate/1 schema tag for automation."
---

With `--format json`, Hayate prints one JSON object per line. Regular events go to stdout and errors go to stderr. Every object has an `event` field naming its type and a `"schema": "hayate/1"` field you can check before parsing.

```json
{
  "event": "transfer_complete",
  "filename": "build.tar.zst",
  "size": 52428800,
  "elapsed_secs": 0.84,
  "speed_bps": 62415238,
  "checksum": "blake3$9f2c…",
  "cipher": "AES-256-GCM",
  "compressed": false,
  "schema": "hayate/1"
}
```

Each event is printed on a single line. It is expanded here for readability.

## Events

<ResponseField name="status" type="level, message">
  A status message. `level` is `info`, `ok` or `warn`.
</ResponseField>

<ResponseField name="stage" type="stage, detail">
  The transfer moved to a new stage.
</ResponseField>

<ResponseField name="field" type="key, value">
  A single labeled value.
</ResponseField>

<ResponseField name="pairing_code" type="code, command">
  `hayate send` generated a pairing phrase. `command` is what the receiver should run.
</ResponseField>

<ResponseField name="peer" type="name, address, os, rtt_ms">
  Discovery found a receiver. `rtt_ms` is `null` when it wasn't measured.
</ResponseField>

<ResponseField name="discover_summary" type="count">
  Discovery finished.
</ResponseField>

<ResponseField name="transfer_offer" type="filename, size, kind, from, cipher, hash">
  A receiver got an offer.
</ResponseField>

<ResponseField name="transfer_info" type="title, fields">
  A group of transfer details. `fields` is an object of strings.
</ResponseField>

<ResponseField name="transfer_complete" type="filename, size, elapsed_secs, speed_bps, checksum, cipher, compressed">
  A transfer finished.
</ResponseField>

<ResponseField name="integrity_verified" type="algo, checksum">
  The checksum was verified.
</ResponseField>

<ResponseField name="bound" type="address, backend">
  A listener bound to an address. `backend` is the I/O backend, such as `io_uring`.
</ResponseField>

<ResponseField name="bound_addresses" type="addresses">
  The addresses a receiver is reachable on.
</ResponseField>

<ResponseField name="error" type="message">
  A command failed. Printed on stderr.
</ResponseField>

Combine JSON output with [exit codes](/cli/exit-codes) to detect the failure type.
